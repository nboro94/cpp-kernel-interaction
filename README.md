# C++ Kernel Interaction Project

This project demonstrates basic interactions with the kernel using C++. It includes examples of system calls and reading system information.

## Project Structure

- `src/`: Contains the source files for the application.
  - `main.cpp`: Entry point of the application.
  - `kernel_interaction.cpp`: Implementation of kernel interaction functions.
  
- `include/`: Contains header files.
  - `kernel_interaction.h`: Declarations for kernel interaction functions.

- `Makefile`: Build instructions for compiling the project.

- `README.md`: Documentation for the project.

## Building the Project

To build the project, navigate to the project directory and run the following command:

```
make
```

This will compile the source files and create the executable.

## Running the Application

After building the project, you can run the application with the following command:

```
./cpp-kernel-interaction
```

## Kernel Interactions Demonstrated

This project showcases the following kernel interactions:

- System calls for process management.
- Reading system information such as uptime and memory usage.

Feel free to explore the source code in the `src` directory to understand how these interactions are implemented.
